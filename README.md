# רופא הצמחים

דף אחד בעברית: מצלמים או מעלים תמונות, גם של כמה צמחים ביחד, ומקבלים זיהוי לכל צמח (עם סימון על התמונה), אבחון של בעיות אפשריות (עם בדיקה שמבדילה ביניהן) והנחיות טיפול.

## איך זה רץ

הניתוח משתמש ביכולת `sample` של artifact ב-Claude (`claude.use("sample")`), ולכן הוא עובד רק כשהדף מפורסם כ-artifact ב-claude.ai עם ההצהרה `{"sample": {"images": true}}`. בלי זה, כשפותחים את הקובץ ישירות או ב-GitHub Pages, כפתור הניתוח מושבת.

להרצה עצמאית צריך להחליף את הקריאה ל-`sample(...)` בקריאה לשרת שלך שמחזיק מפתח API של Anthropic (לא להכניס את המפתח לדף). אפשר להוסיף נתיב כזה לשרת ה-Cloudflare Worker.

## קבצים

- `index.html` הכול בקובץ אחד: ממשק, העלאת תמונות והקטנה בדפדפן, בניית הבקשה והצגת התוצאה.

## פרטיות

התמונות נשארות בדפדפן ונשלחות רק לניתוח. ב-localStorage נשמרים רק שם הצמח וסיכום קצר של אבחונים קודמים.
